# Дорофеев Артем — портфолио

Одностраничный сайт видеографа: русский и английский языки, десять работ, фотографии, видеоподложка и контакт в Telegram. Все медиа и шрифты размещены вместе с сайтом.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Подключение artifullhd.ru выполняется после проверки первого опубликованного адреса.
